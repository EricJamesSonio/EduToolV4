## Plan: Rubric → Grading Scheme Migration

### 1. Database
- Run `prisma migrate dev --name replace_rubric_with_grading_scheme`
- This drops `Rubric`, creates `GradingScheme` + `GradingSchemeComponent`
- Regenerate client: `prisma generate`

---

### 2. Delete the entire rubric module
```
src/modules/rubric/   ← delete entire folder
```
Also remove rubric from whatever domain module imports it (likely `class-domain.module.ts` or `academic-domain.module.ts`).

---

### 3. Create the new grading-scheme module
New folder structure to create from scratch:
```
src/modules/grading-scheme/
├─ dto/
│   └─ grading-scheme.dto.ts        ← CreateGradingSchemeDto, UpdateGradingSchemeDto, with nested ComponentDto
├─ entity/
│   └─ grading-scheme.entity.ts
├─ grading-scheme.repository.ts     ← CRUD for GradingScheme + GradingSchemeComponent
├─ grading-scheme.service.ts        ← business logic + locking
├─ grading-scheme.controller.ts     ← routes
├─ grading-scheme.module.ts
├─ grading-scheme.service.spec.ts
└─ grading-scheme.controller.spec.ts
```

**Repository methods needed:**
- `create(data)` — creates scheme + components in a transaction
- `findAll(orgId, filters)` — filter by `class_id`, `educator_id`, `is_default`
- `findById(id, orgId)`
- `update(id, data)` — replace components via deleteMany + createMany
- `softDelete` or hard delete
- `lockForClass(classId, orgId)` — replaces the old `lockRubricForClass` from ClassRepository
- `findByClass(classId, orgId)` — get all schemes for a class

---

### 4. Fix ClassRepository
Remove `lockRubricForClass` — that method is now dead since `Rubric` model is gone. The equivalent lives in the new `GradingSchemeRepository.lockForClass`.

---

### 5. Fix any service that referenced rubric
From the codebase so far, the only confirmed reference is `ClassRepository.lockRubricForClass`. Scan these files just in case:
- `class.service.ts` — check if it calls `lockRubricForClass`
- `grade-lock.service.ts` — locking flows sometimes triggered rubric locking
- `class-domain.module.ts` / `academic-domain.module.ts` — remove rubric module import/registration

---

### 6. Register the new module
Add `GradingSchemeModule` to the appropriate domain module. Given its nature (academic + class-scoped), it fits best in `class-domain.module.ts`.
