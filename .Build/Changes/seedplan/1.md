SEED DATA PLAN
==============
These are the default values an admin gets when they set up a new org.
All of it is optional — admin can pick/unpick during onboarding or later.


════════════════════════════════════════
1. PROGRAMS
════════════════════════════════════════
A program is the top-level grouping. Fill in the ones that apply to your school.

Examples:
  - name: "Basic Education"       type: "k12"
  - name: "Senior High School"    type: "shs"
  - name: "College"               type: "college"
  - name: "Technical-Vocational"  type: "tvet"

→ You decide which programs your platform supports.
→ Each program will own the levels, courses, and strands below it.


════════════════════════════════════════
2. LEVELS  (per program)
════════════════════════════════════════
Levels are the year/grade levels inside a program.

For k12 (Basic Education):
  Grade 1, Grade 2, Grade 3, Grade 4, Grade 5, Grade 6   ← Elementary
  Grade 7, Grade 8, Grade 9, Grade 10                    ← Junior High

For shs (Senior High School):
  Grade 11, Grade 12

For college:
  1st Year, 2nd Year, 3rd Year, 4th Year   (or Year 1–5 for 5-yr programs)

For tvet:
  NC I, NC II  (or whatever your institution uses)

→ Provide: name, which program it belongs to.
→ school_year_id stays null at seed time (linked when school year is created).


════════════════════════════════════════
3. SECTIONS  (per level)
════════════════════════════════════════
Default section names per level. Admin can add/remove later.

Common pattern:
  Each level gets sections like: Section A, Section B, Section C
  Or named: Rizal, Bonifacio, Mabini  (your call)

→ Provide: section names and default capacity per section.
→ Example capacity: 40 or 45.


════════════════════════════════════════
4. COURSES  (per program, for college/shs)
════════════════════════════════════════
Courses group subjects. Only relevant for college and SHS.

For SHS:
  - STEM, ABM, HUMSS, GAS, TVL, Sports, Arts & Design

For college:
  - BS Computer Science, BS Information Technology,
    BS Nursing, BS Education, BS Accountancy, etc.
  (Fill in only what your school offers)

For k12:
  → No courses needed. Subjects live directly under the level.

→ Provide: course name, short code (e.g. "BSCS"), which program.


════════════════════════════════════════
5. STRANDS  (for SHS only)
════════════════════════════════════════
Strands are sub-tracks inside SHS, linked to a program.

Common strands:
  Under STEM:  (no sub-strand usually)
  Under TVL:   Home Economics, ICT, Industrial Arts, Agri-Fishery

→ Only fill this if your SHS has strand-level tracking.
→ If not needed, skip — it's optional in the schema.


════════════════════════════════════════
6. GRADING SCALES  (per level)
════════════════════════════════════════
A grading scale maps a final score (float) to a grade label (string).
Each level can have its own scale. Stored as a JSON `ranges` array.

You need to provide for each level:
  - Scale name  (e.g. "DepEd K-12 Scale")
  - Score ranges → grade label

Example for k12 (DepEd standard):
  90–100  → Outstanding        (or "O")
  85–89   → Very Satisfactory  (or "VS")
  80–84   → Satisfactory       (or "S")
  75–79   → Fairly Satisfactory(or "FS")
  below 75→ Did Not Meet       (or "DNM")

Example for college (common PH university):
  95–100  → 1.0
  90–94   → 1.25
  85–89   → 1.5
  80–84   → 1.75
  75–79   → 2.0
  70–74   → 2.25
  65–69   → 2.5
  60–64   → 2.75
  55–59   → 3.0
  below 55→ 5.0  (Failed)

→ Provide: the scale name and all ranges with min, max, and label.
→ One scale per level is enough for seed. Admin can add more later.


════════════════════════════════════════
7. GRADING SCHEME  (org default)
════════════════════════════════════════
One default grading scheme for the whole org.
This is what every class falls back to if no specific scheme is assigned.
Components must total 100% (required ones).

Example for k12 (DepEd WW/PT/QA breakdown):
  Written Works   type: written_work   weight: 30%
  Performance     type: performance    weight: 50%
  Quarterly Exam  type: exam           weight: 20%

Example for college:
  Quizzes         type: quiz           weight: 25%
  Activities      type: activity       weight: 25%
  Midterm Exam    type: exam           weight: 25%
  Final Exam      type: exam           weight: 25%
  (note: two exam components — you can name them differently)

→ Provide: component name, type (must match Assessment.type or "manual"),
  weight, and whether it's optional.
→ This becomes the org-level default. Educators can override per class.


════════════════════════════════════════
8. SUBJECTS  (per level + course/strand)
════════════════════════════════════════
Subjects are the actual classes taught. This is the biggest seed list.

For k12 core subjects (each grade level):
  English, Filipino, Mathematics, Science, Araling Panlipunan,
  Edukasyon sa Pagpapakatao (EsP), MAPEH, Technology & Livelihood Ed (TLE)

For SHS core (all strands):
  Oral Communication, Reading & Writing, Komunikasyon,
  21st Century Literature, Contemporary PH Arts, Media & Info Literacy,
  General Mathematics, Statistics & Probability,
  Earth & Life Science, Physical Science,
  Introduction to Philosophy, Personal Development,
  Understanding Culture, PE & Health

For SHS specialized (per strand, e.g. STEM):
  Pre-Calculus, Basic Calculus, General Biology 1 & 2,
  General Chemistry 1 & 2, General Physics 1 & 2

For college (per course):
  Fill in your actual curriculum subjects per year level.

→ Provide per subject: name, which level, which course or strand (if any),
  year_level label (e.g. "1st Year"), term_label (e.g. "1st Semester").


════════════════════════════════════════
SEED SELECTION MATRIX
(what the admin sees during onboarding)
════════════════════════════════════════

Step 1 — Pick your programs
  [ ] Basic Education (K-12)
  [ ] Senior High School
  [ ] College
  [ ] Technical-Vocational

Step 2 — Per selected program, pick levels
  (pre-checked based on program, admin can uncheck)

Step 3 — Pick default sections per level
  How many sections? [ 1 / 2 / 3 / custom ]
  Section naming: [ A/B/C  |  1/2/3  |  Named (Rizal, etc.) ]

Step 4 — Pick courses/strands (for SHS/college only)
  (list of available courses, admin checks which ones to activate)

Step 5 — Pick grading scale per level
  (show presets: DepEd K-12, University Scale, Custom)

Step 6 — Pick default grading scheme
  (show presets, admin can edit weights before confirming)

Step 7 — Pick subjects
  (pre-checked standard curriculum, admin can uncheck or add custom)
