CLASSES PAGE PLAN

OVERVIEW:
- The Classes page uses a shared School Year selector (global context).
- All class creation and display are scoped to the selected School Year.

--------------------------------------------------

CREATE CLASS FLOW

1. School Year
- Automatically based on the selected School Year from the page
- No manual input required in the dialog

2. Program (Required)
- User selects the academic program
  (e.g., College, SHS, Customs, etc.)

3. Course / Strand / Track (Conditional)
- Only shown if the selected Program has sub-classifications
  - College → Courses (e.g., BSCS, BSIT)
  - SHS → Strands (e.g., STEM, ABM)
- If not applicable, skip this step and proceed to Level

4. Level (Required)
- Filtered based on selected Program (and Course/Strand if applicable)
  - Example:
    - College → 1st Year, 2nd Year, etc.
    - SHS → Grade 11, Grade 12

5. Section (Required)
- Filtered based on selected Level
  - Example:
    - 1st Year → Sections A, B, C

--------------------------------------------------

FINAL CLASS STRUCTURE

A class is uniquely defined by:
- School Year
- Program
- Course/Strand (optional)
- Level
- Section

Example:
- 2026–2027 / College / BSCS / 1st Year / Section A

--------------------------------------------------

SCHEDULING

After defining the class, assign schedule entries:

- A class can have multiple schedules
- Each schedule includes:
  - Day of Week (e.g., Monday, Wednesday)
  - Start Time
  - End Time

Example:
- BSCS 1-A
  - Monday 8:00–10:00
  - Wednesday 8:00–10:00

--------------------------------------------------

DISPLAY FORMAT

Classes should be displayed in a clean, grouped format:

Format Options:
- "College - BSCS - 1A"
- "BSCS 1A (College)"

Each entry represents a class with its associated schedule(s)

--------------------------------------------------

RULES & CONSTRAINTS

- School Year is always derived from the global selector
- Course/Strand is optional depending on Program
- Prevent duplicate classes with same:
  (School Year + Program + Course/Strand + Level + Section)
- Section must exist before creating a class
- Handle cases where no sections are available
