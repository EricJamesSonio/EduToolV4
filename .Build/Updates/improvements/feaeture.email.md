Feature: Optional Email Notifications

In the system, accounts are created only by the admin.
Users (educators and students) are not required to have an email.

However, each user has the option to add their own email address if they want.

This email is used only for notifications, such as:

announcements
assessments
system updates

If a user chooses to add an email, they can:

receive notifications without logging into the system

If they don’t:

they will continue receiving notifications only inside the system

The email is:

optional
user-controlled
not used for authentication
