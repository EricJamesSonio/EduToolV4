1. Letter Grade / Percentage Scale

A+  97-100  Excellent
A   93-96   Very Good
A-  90-92   Good
B+  87-89   Above Average
B   83-86   Satisfactory
B-  80-82   Fair
C+  77-79   Pass
C   75-76   Conditional Pass
F   0-74    Fail

------------------------------------------------------------
2. 1.0 – 5.0 Numeric Scale (Higher Education / Universities)

1.0  Excellent
1.25 Very Good
1.5  Very Good
1.75 Good
2.0  Good
2.25 Satisfactory
2.5  Satisfactory
2.75 Passing
3.0  Passing
4.0  Conditional Fail
5.0  Fail

* Some schools use 1.0–4.0 with 3.0 as passing.
* Variations exist depending on the university.

------------------------------------------------------------
3. K–12 / Basic Education 60–100% Passing Scale

90-100 Outstanding
85-89  Very Satisfactory
80-84  Satisfactory
75-79  Fairly Satisfactory
Below 75 Did Not Meet Expectations / Fail

* Used mostly in public and private K–12 schools.
* Some schools use numerical grades only (e.g., 60 as passing).

------------------------------------------------------------
4. Pass/Fail / Credit System (Colleges / Vocational)

CR  Credit / Passed
NC  No Credit / Failed
P   Pass
F   Fail

* Often used for non-core or elective courses.

------------------------------------------------------------
5. Other Variations

1.0 – 1.5 = A
1.75 – 2.0 = B
2.25 – 2.75 = C
3.0 = D (Lowest Passing)
5.0 = Failing

* Vocational or technical courses sometimes use distinction / merit / satisfactory / fail.
