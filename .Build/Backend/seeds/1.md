# 🔥 1. CORE SYSTEM BOOTSTRAP (MUST HAVE)

These make the system usable immediately after login.

### ✅ Platform Owner

* 1 account

```txt
email: owner@edutool.com
password: owner123
role: platform_owner
```

### ✅ Admin (1 org)

* 1–2 admins max (keep simple demo)

```txt
email: admin@greenfield.edu
org: Greenfield Academy
```

### ✅ Organization

```txt
Name: Greenfield Academy
Description: Demo school for EduTool
```

---

# 🏫 2. ORGANIZATION STRUCTURE (CRITICAL FOR DEMO)

This is where most demos fail — you need *complete structure*.

### ✅ Programs

Seed at least:

* Elementary
* High School
* Senior High
* College

---

### ✅ Level Defaults (IMPORTANT)

Keep it small but realistic:

```txt
Elementary:
  Grade 1 → Sections: A, B

High School:
  Grade 7 → Sections: A, B

Senior High:
  Strand: STEM
    Grade 11 → Sections: A

College:
  Course: BSCS (4 years)
    Year 1 → Sections: A
```

---

### ✅ Sections with Capacity

```txt
Grade 7 - Section A → capacity: 3
Grade 7 - Section B → capacity: 3
```

👉 Keep capacity LOW to trigger:

* Pending students
* Overflow logic

# 👩‍🏫 3. USERS (VERY IMPORTANT FOR STORY)

```txt
Juan Dela Cruz → Math

```

### ✅ Students (10–15 total)

Mix them across:

* Sections
* Statuses

Example:

| Name      | Section | Status                 |
| --------- | ------- | ---------------------- |
| Student 1 | G7-A    | Active                 |
| Student 2 | G7-A    | Active                 |
| Student 3 | G7-A    | Active                 |
| Student 4 | G7-A    | Pending (capacity hit) |
| Student 5 | G7-B    | Active                 |
| Student 6 | STEM 11 | Active                 |
| Student 7 | BSCS 1  | Active                 |
| Student 8 | BSCS 1  | Suspended              |
| Student 9 | G7-B    | Dropped                |

👉 This is **VERY important** — shows:

* All statuses working
* Capacity system working
* Filtering working

# 🧠 PRO TIP (VERY IMPORTANT)

Don’t just seed random data — seed **SCENARIOS**:

### 🎯 Demo Flow Example:

1. Login as Admin
2. Show dashboard stats
3. Open students → show statuses
4. Open class → show:

   * lessons
   * assessments
   * attendance
5. Show:

   * pending student
   * full section
6. Switch to student:

   * take assessment
7. Switch to educator:

   * publish scores
8. Back to student:

   * see grades

👉 That’s how you make it feel like a **real SaaS product**
