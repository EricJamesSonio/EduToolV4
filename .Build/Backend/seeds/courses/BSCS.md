BS Computer Science (BSCS)

MAJOR SUBJECTS (CORE CS)

1. Introduction to Computing
   Year/Term: 1st Year, 1st Semester
   Prerequisite: None

2. Computer Programming 1
   Year/Term: 1st Year, 1st Semester
   Prerequisite: Introduction to Computing

3. Computer Programming 2
   Year/Term: 1st Year, 2nd Semester
   Prerequisite: Computer Programming 1

4. Discrete Mathematics
   Year/Term: 1st Year, 2nd Semester
   Prerequisite: None

5. Object-Oriented Programming
   Year/Term: 2nd Year, 1st Semester
   Prerequisite: Computer Programming 2

6. Data Structures and Algorithms
   Year/Term: 2nd Year, 2nd Semester
   Prerequisite: Object-Oriented Programming, Discrete Mathematics

7. Algorithms and Complexity
   Year/Term: 3rd Year, 1st Semester
   Prerequisite: Data Structures and Algorithms

8. Automata Theory
   Year/Term: 3rd Year, 1st Semester
   Prerequisite: Discrete Mathematics

9. Programming Languages
   Year/Term: 3rd Year, 2nd Semester
   Prerequisite: Object-Oriented Programming, Data Structures and Algorithms

10. Software Engineering
    Year/Term: 3rd Year, 2nd Semester
    Prerequisite: Object-Oriented Programming

11. Database Systems
    Year/Term: 2nd Year, 2nd Semester
    Prerequisite: Computer Programming 2

12. Operating Systems
    Year/Term: 3rd Year, 1st Semester
    Prerequisite: Data Structures and Algorithms, Computer Architecture

13. Computer Networks
    Year/Term: 3rd Year, 2nd Semester
    Prerequisite: Operating Systems

14. Artificial Intelligence
    Year/Term: 4th Year, 1st Semester
    Prerequisite: Data Structures and Algorithms, Algorithms and Complexity

15. Machine Learning (optional in some schools)
    Year/Term: 4th Year, 2nd Semester
    Prerequisite: Artificial Intelligence, Data Structures and Algorithms

16. Human-Computer Interaction
    Year/Term: 3rd Year, 2nd Semester
    Prerequisite: Software Engineering

17. Computer Architecture
    Year/Term: 2nd Year, 2nd Semester
    Prerequisite: Introduction to Computing, Object-Oriented Programming

18. Numerical Methods
    Year/Term: 3rd Year, 1st Semester
    Prerequisite: Discrete Mathematics

19. CS Thesis / Capstone Project
    Year/Term: 4th Year, 2nd Semester
    Prerequisite: Completion of all core CS subjects
