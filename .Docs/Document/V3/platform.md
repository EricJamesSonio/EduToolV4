EDUTOOL — PLATFORM OWNER DOMAIN
=================================

SCOPE
-----
Platform Owner is the EduTool team. Their entire scope is Admin account
management. They have ZERO visibility into any organization's internal data —
no students, no educators, no classes, no grades, no structure of any kind.

CAPABILITIES
------------
- Create a new Admin account (one per school)
- View all existing Admin accounts and their credentials
- View a specific Admin's password in plain text (for distributing to the school)
- Copy Admin credentials for distribution
- Reset an Admin's password
- Block an Admin account (disables login; the org and its data are unaffected)
- Unblock a blocked Admin account

WHAT PLATFORM OWNER CANNOT DO
------------------------------
- See any org's name, description, or internal structure
- See any students, educators, classes, subjects, grades, or logs within an org
- Enter or interact with any org in any way
- Override anything inside an org

SCHOOL ONBOARDING FLOW
-----------------------
1. School negotiates with platform owner.
2. Platform owner manually creates one Admin account for the school.
3. Admin logs in and creates their Organization (sets name and description).
4. Org is active. Platform owner's involvement ends here.

NOTES
-----
- One Admin account per school. This is enforced — no reuse across schools.
- Blocking an Admin only disables login. The org and all its data remain intact.
- Platform Owner knows an Admin exists only because they created it. Nothing else.
