Okay let's get serious about this. Let me go through the whole system critically and flag everything that needs to be solidified before a single line of code is written.

---

**The things I think need the most attention:**

---

**1. Organization Verification — who can create a school?**

Right now any random person can register as Admin and create an "organization." In a real school system that's a problem. Anyone could spin up a fake school, pull in educators and students. Should there be any vetting? Even something simple like:
- Email domain restriction (e.g. only `@school.edu` admins)
- Or a platform-level Super Admin that approves new organizations before they go live

This is a trust and safety question that affects the whole system.

---

**2. Student org scoping is too loose**

Right now students just *pick* their org on registration. That means any student can claim to be in any school. There's no verification. Should students instead:
- Get an invite code or enrollment code from their school's Admin
- Or require Admin approval similar to how educators request to join

---

**3. What happens when an educator leaves an org?**

If an Admin removes an educator from an org — what happens to their existing classes, lessons, assessments, and student grades tied to them? This needs a clear rule before building, otherwise you'll have orphaned data everywhere.

---

**4. Grade finalization — is there a "lock" mechanism?**

Grades auto-recompute whenever anything changes. But at end of semester, teachers need to *submit* final grades. Is there a grade finalization / locking step? Without it, a teacher could accidentally change a grade after the semester closes.

---

**5. Assessment integrity**

Once a student starts an assessment, what are the rules? Right now this isn't defined at all:
- Time limits?
- Can they exit and return?
- What if they lose connection mid-assessment?
- Can the educator see who has opened it vs submitted?

---

**6. The "Behavior" grade gap**

30% of the grade is manually entered with zero structure. That's a big chunk. Should behavior have sub-categories? Like attendance, participation, conduct — each with their own weight? Otherwise it's just a freeform number with no audit trail.

---

Those are the six biggest gaps I see. Which ones do you want to tackle first — or do any of these surprise you?
