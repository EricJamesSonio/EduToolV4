# Assessment Management

User inserts txt file containing raw lesson
Program ask type of assessment (Exam, Activity, Quiz etc.)
Program ask for template (1-10 True or False, 11-20 Multiple choice etc.)
Program automates the generation of assessment.
Program gives preview, User reviews it.
User can manually edit that preview
Program also has the correct answers.

user has two option. Paste the lesson there or insert a txt.
