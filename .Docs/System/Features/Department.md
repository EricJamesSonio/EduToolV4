Department management
    - List of departments (BSBA, BSA, BSCS etc)
    - Semester : Main semester setting (Select from semester list)
        - Purpose of this semester selection is the schedules created here, will be depends on this setting.
        - The schedules in here start and also end based on the semester setting.
        - Additional notes : This is useful for educator level view. since the weeks are need to be computed and the computation is based on the time frame of the semester like week 1 - week13
