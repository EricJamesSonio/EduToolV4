# EduTool — Technology Stack (Detailed Clean Version)

**Language:** TypeScript

**Frontend:**

* **Next.js** (framework)
* **React** (UI library)
* **Tailwind CSS** (styling)
* **React Query / TanStack Query** (data fetching & caching)

**Backend:**

* **NestJS** (API framework)
* **REST API**

**Database:**

* **PostgreSQL**
* **Prisma** (ORM / schema management)

**Real-Time & Notifications:**

* **Socket.IO** (real-time communication)
* **Redis** (caching, queues, session store)

**Background Jobs / Queues:**

* **BullMQ** (job processing)

**Video Meetings:**

* **WebRTC** (real-time video/audio)
* **mediasoup** (optional for scalable media server)

**Authentication & Security:**

* **JWT** (sessions & API auth)
* **bcrypt** (password hashing)
* Role-based access control

**File Storage:**

* **AWS S3** or compatible object storage

**Deployment & Infrastructure:**

* **Docker** (containerization)
* Cloud hosting: AWS / DigitalOcean / GCP

**Version Control:**

* **Git** (GitHub / GitLab)

**Dev Tools / Code Quality:**

* **ESLint** (linting)
* **Prettier** (formatting)
* **VS Code** (IDE)

**Optional / Future:**

* AI grading / assessment tools
* Advanced analytics pipelines
* Mobile clients (React Native or Next.js PWA)
