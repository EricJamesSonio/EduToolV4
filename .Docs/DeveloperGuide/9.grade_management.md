# DEV-09 — Grade Management
**EduTool Developer Guide**
> Covers: Rubric system, grade computation, display modes, grade locking, grading scale, exports and class cards.

---

## 1. Overview

Grades in EduTool are computed from a rubric — a weighted set of categories, some linked to assessments and some entered manually. The educator builds and owns the rubric. It locks once students are enrolled. Grade locking is a permanent, irreversible action (with a platform-owner override path for extreme cases).

---

## 2. Rubric System

### 2.1 Data Models

```
RubricTemplate
  id              UUID, primary key
  owner_type      enum (ORG_DEFAULT | EDUCATOR_LIBRARY | CLASS)
  org_id          FK → Organization
  educator_id     FK → Educator, nullable (null for ORG_DEFAULT)
  name            string
  created_at      timestamp

RubricCategory
  id              UUID, primary key
  rubric_id       FK → RubricTemplate
  name            string, e.g. "Quizzes", "Attendance"
  weight          decimal  -- percentage, e.g. 20.00
  entry_type      enum (ASSESSMENT_LINKED | MANUAL_ENTRY)
  assessment_type FK → Assessment.type enum, nullable
                  -- if ASSESSMENT_LINKED, which type of assessments
                  -- e.g. QUIZ, ACTIVITY, EXAM
  order           integer  -- display order

ClassRubric
  id              UUID, primary key
  class_id        FK → Class, unique
  rubric_id       FK → RubricTemplate  -- the template used
  is_locked       boolean, default false
  locked_at       timestamp, nullable
```

### 2.2 Validation

- All `RubricCategory.weight` values for a given rubric must sum to exactly **100.00**.
- Validate on save. Return error per-category if sum ≠ 100.

### 2.3 Rubric Assignment at Class Creation

When a class is created, the educator (or Admin) assigns a rubric using one of:

```
(a) ORG_DEFAULT — clone the org's default RubricTemplate as a new CLASS rubric
(b) EDUCATOR_LIBRARY — clone a saved rubric from the educator's personal library
(c) BUILD_FROM_SCRATCH — create a new RubricTemplate with owner_type = CLASS
```

In all cases, a **copy** is made and attached to the class as a `ClassRubric`. Modifying the class rubric does not affect the template it was copied from.

### 2.4 Rubric Lock Rule

```
FUNCTION checkRubricLock(class_id):
  rubric = getClassRubric(class_id)
  IF rubric.is_locked:
    RETURN error: "Rubric is locked. It cannot be modified once students
                   are enrolled."

FUNCTION lockRubricIfNeeded(class_id):
  -- Called every time a student is enrolled in the class
  rubric = getClassRubric(class_id)
  IF NOT rubric.is_locked:
    enrollment_count = countActiveEnrollments(class_id)
    IF enrollment_count >= 1:
      UPDATE ClassRubric SET is_locked = true, locked_at = now()
      WHERE class_id = class_id
```

### 2.5 Educator Rubric Library

Educators can save rubrics to their personal library from any class rubric they built.

```
RubricTemplate (owner_type = EDUCATOR_LIBRARY, educator_id = ...)
```

Saving to library = cloning the class rubric into a new template with `owner_type = EDUCATOR_LIBRARY`.

## 3. Grade Computation

### 3.1 StudentGrade Model

```
StudentGrade
  id              UUID, primary key
  class_id        FK → Class
  student_id      FK → Student
  rubric_id       FK → ClassRubric

  -- Per-category scores (stored as JSON for flexibility)
  category_scores JSON:
    [
      {
        "category_id": "...",
        "name": "Quizzes",
        "entry_type": "ASSESSMENT_LINKED",
        "weight": 20.00,
        "raw_score": 88.5,   -- average of all quiz assessments
        "weighted_score": 17.7  -- raw_score * (weight/100)
      },
      {
        "category_id": "...",
        "name": "Attendance",
        "entry_type": "MANUAL_ENTRY",
        "weight": 10.00,
        "raw_score": 95.0,   -- educator-entered
        "weighted_score": 9.5
      },
      ...
    ]

  final_grade_percentage  decimal  -- sum of all weighted_scores
  final_grade_value       string   -- from grading scale, e.g. "1.25", "A", "Outstanding"
  final_grade_remark      string   -- e.g. "Passed", "Failed", "Incomplete"
  is_passing              boolean
  is_locked               boolean, default false
  locked_at               timestamp, nullable
  locked_by               enum (EDUCATOR | AUTO_LOCK | PLATFORM_OVERRIDE)
```

### 3.2 ASSESSMENT_LINKED Category Computation

```
FUNCTION computeAssessmentLinkedScore(class_id, student_id, category):
  -- Get all assessments of the matching type in this class
  assessments = getAssessments(class_id,
                  type: category.assessment_type,
                  status: NOT DELETED)

  IF assessments.length = 0:
    RETURN null  -- no assessments yet, score is empty

  total_score = 0
  total_weight = 0

  FOR each assessment in assessments:
    sa = getStudentAssessment(student_id, assessment.id)

    IF sa IS NULL OR sa.status = NULL:
      -- Treated as 0 for this assessment
      total_weight += assessment.total_items
      total_score += 0

    ELIF sa.status = EXEMPTED:
      -- Excluded from denominator AND numerator
      -- (counts as if they had a perfect score — excluded, not penalized)
      CONTINUE

    ELIF sa.status = CUSTOM:
      total_weight += assessment.total_items
      total_score += sa.custom_score

    ELIF sa.status = SUBMITTED:
      -- Handle pending essay grades
      has_ungraded_essay = existsUngraded EssayGrade for this sa
      IF has_ungraded_essay:
        -- Show as "incomplete" — do not compute yet
        RETURN INCOMPLETE

      total_weight += assessment.total_items
      total_score += sa.score

  IF total_weight = 0:
    RETURN null

  RETURN (total_score / total_weight) * 100
```

### 3.3 Final Grade Computation

```
FUNCTION computeFinalGrade(class_id, student_id):
  rubric = getClassRubric(class_id)
  categories = getRubricCategories(rubric.id)

  final_percentage = 0
  any_incomplete = false

  FOR each category in categories:
    IF category.entry_type = ASSESSMENT_LINKED:
      raw = computeAssessmentLinkedScore(class_id, student_id, category)
      IF raw = INCOMPLETE:
        any_incomplete = true
        CONTINUE
    ELSE:
      raw = getManualScore(class_id, student_id, category.id)
        -- educator-entered value in ManualGradeEntry table

    IF raw IS NULL:
      weighted = 0
    ELSE:
      weighted = raw * (category.weight / 100)
    final_percentage += weighted

  -- Apply grading scale
  scale_entry = matchGradingScale(class.level_section, final_percentage)

  RETURN {
    final_grade_percentage: final_percentage,
    final_grade_value: scale_entry.grade_value,
    final_grade_remark: scale_entry.remark,
    is_passing: final_percentage >= scale_entry.passing_threshold,
    has_incomplete: any_incomplete
  }
```

### 3.4 Manual Grade Entry Model

```
ManualGradeEntry
  id              UUID, primary key
  class_id        FK → Class
  student_id      FK → Student
  category_id     FK → RubricCategory
  score           decimal  -- 0-100
  entered_by      FK → Educator
  entered_at      timestamp

```

## 4. Grade Display Modes

### 4.1 Clean Mode

Groups scores by rubric category. Educator sees category name, total weight, and average score for each student. Clicking a category drills into individual assessment scores.

### 4.2 Excel Mode

Flat table with one row per student and one column per individual assessment + manual category. All scores visible at once.

Both modes read from the same underlying data — they are view presentations only.

## 5. Grade Locking

### 5.1 Grade Lock Window (Admin)

```
GradeLockWindow
  id              UUID, primary key
  org_id          FK → Organization
  school_year_id  FK → SchoolYear
  semester_id     FK → SemesterPeriod
  deadline        timestamp  -- auto-lock fires at this time
  opened_by       FK → User (Admin)
  opened_at       timestamp
```

When Admin opens a lock window:
- NOTIFY all educators in the org: "Grade locking window is open. Deadline: [deadline]."
- Educators can lock their classes manually until the deadline.

### 5.2 Manual Lock by Educator

```
FUNCTION lockGrades(class_id, educator_id):

  -- Check for ungraded essays
  ungraded_essays = getUngradedEssays(class_id)
  IF ungraded_essays.length > 0:
    WARN educator: "[N] essay question(s) are not yet graded.
      If you lock now, those scores will be treated as 0.
      You take full responsibility. Proceed?"
    -- Educator confirms — system allows locking regardless

  -- Finalize grade computation for all students
  students = getActiveEnrollments(class_id)
  FOR each student in students:
    grade = computeFinalGrade(class_id, student.id)
    UPDATE StudentGrade SET
      final_grade_percentage = grade.final_grade_percentage,
      final_grade_value = grade.final_grade_value,
      final_grade_remark = grade.final_grade_remark,
      is_passing = grade.is_passing,
      is_locked = true,
      locked_at = now(),
      locked_by = EDUCATOR
    WHERE class_id = class_id AND student_id = student.id

  -- Auto-publish all unpublished scores
  UPDATE StudentAssessment SET score_published = true
  WHERE assessment_id IN (SELECT id FROM Assessment WHERE class_id = class_id)

  UPDATE Class SET grades_locked = true
  LOG educator activity: event_type = GRADES_LOCKED
  LOG admin audit: action_type = GRADES_LOCKED, details = { class_id, educator_id }

  -- Notify students
  students_in_class = getEnrolledStudents(class_id)
  FOR each student in students_in_class:
    NOTIFY student: "Your grades for [class title] are now available."
```

### 5.3 Auto-Lock on Deadline

```
SCHEDULED JOB (runs every minute):
  lock_windows = getGradeLockWindows WHERE deadline <= now() AND not closed

  FOR each window:
    unlocked_classes = getClasses WHERE
      school_year_id = window.school_year_id
      AND semester_id = window.semester_id
      AND grades_locked = false
      AND is_archived = false

    FOR each class in unlocked_classes:
      lockGrades(class.id, locked_by: AUTO_LOCK)
      NOTIFY educator: "Grades for [class title] were automatically locked
        because the deadline passed."
```

### 5.4 Platform Override (Unlock)

Only the platform owner can unlock grades after locking, only on formal Admin request.

```
PlatformOverrideLog
  id              UUID, primary key
  class_id        FK → Class
  requested_by    FK → User (Admin)
  approved_by     FK → User (Platform Owner)
  reason          text
  unlocked_at     timestamp
```

```
FUNCTION unlockGrades(class_id, platform_owner_id, reason):
  UPDATE StudentGrade SET is_locked = false WHERE class_id = class_id
  UPDATE Class SET grades_locked = false WHERE id = class_id
  CREATE PlatformOverrideLog { class_id, approved_by, reason, unlocked_at }
  LOG admin audit: action_type = GRADE_LOCK_OVERRIDE
```

## 6. Grading Scale

### 6.1 Data Model

```
GradingScale
  id              UUID, primary key
  org_id          FK → Organization
  school_year_id  FK → SchoolYear
  level_section   enum
  is_locked       boolean, default false

GradingScaleEntry
  id              UUID, primary key
  scale_id        FK → GradingScale
  range_min       decimal  -- e.g. 97.00
  range_max       decimal  -- e.g. 100.00
  grade_value     string   -- e.g. "1.00", "A", "Outstanding"
  remark          string   -- e.g. "Passed", "Failed", "Incomplete"
  passing_threshold  decimal  -- min score to be considered passing
```

### 6.2 Validation

- Ranges for a scale must cover 0.00–100.00 fully.
- No gaps: sorted entries must be contiguous.
- No overlaps: `entries[i].range_max + epsilon = entries[i+1].range_min`.
- Validate on save.

### 6.3 Lock Behavior

```
FUNCTION lockGradingScaleIfNeeded(org_id, school_year_id, level_section):
  -- Called whenever a grade is locked for a class in this level section
  scale = getGradingScale(org_id, school_year_id, level_section)
  IF scale AND NOT scale.is_locked:
    UPDATE GradingScale SET is_locked = true WHERE id = scale.id
```

Scale auto-unlocks when Admin creates or activates a new school year.

## 7. Grade Export & Class Cards

### 7.1 PDF — Per Student Class Card

Contents:
- Student name, Student ID
- Class title, subject, semester, school year
- Educator name (at time of grade finalization — from `ClassOwnershipLog`)
- Org name
- Per rubric category: name, weight, raw score, weighted score
- Final grade percentage
- Final grade value and remark
- Passing / Failed indicator

Generate using a PDF library. Render per student on demand.

```
GET /classes/{class_id}/students/{student_id}/class-card
  → Returns PDF binary
  → Auth: Admin or Educator of this class
```

### 7.2 CSV — Full Class Export

One row per student:
```
Student Name | Student ID | [Category 1 Score] | [Category 2 Score] | ... |
Final Grade % | Final Grade Value | Remark | Passing Status
```

```
GET /classes/{class_id}/export/csv
  → Returns CSV attachment
  → Auth: Admin or Educator of this class
```
