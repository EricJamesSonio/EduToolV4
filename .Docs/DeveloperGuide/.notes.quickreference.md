## Dependency Graph (quick reference)

Read this before starting any module. The arrows mean "must exist first."

```
DEV-11  ←────────────────── everything writes to it
  ↑ (built first, no deps)

DEV-01  ←── DEV-02, DEV-03, DEV-05, DEV-09, DEV-10
  (org structure — everything references it)

DEV-02  ←── (needs DEV-01, DEV-11, DEV-03's enrollment service, DEV-05's enrollment engine)

DEV-05  ←── DEV-03 (enrollment service), DEV-08 (attendance), DEV-09 (rubric lock), DEV-11
  (class creation triggers all three)

DEV-03  ←── DEV-05 (class matching), DEV-08 (attendance on enroll), DEV-09 (rubric lock), DEV-11

DEV-04  ←── DEV-05 (active class check), DEV-09 (grade attribution), DEV-11

DEV-06  ←── DEV-05 (class + session), DEV-11

DEV-07  ←── DEV-05 (class), DEV-06 (concept build), DEV-08 (auto-attendance), DEV-09 (recompute), DEV-11

DEV-08  ←── DEV-05 (session + enrollment), DEV-09 (grade lock check)
  (called BY DEV-05 and DEV-07 — has no outbound calls except to DEV-09 for lock check)

DEV-09  ←── DEV-01 (grading scale), DEV-04 (class card attribution),
             DEV-05 (enrollment), DEV-07 (assessment scores), DEV-11

DEV-10  ←── DEV-01 (calendar), DEV-05 (class + enrollment), DEV-06 (lesson content), DEV-11
```

### Safe build order that respects all dependencies

```
1. DEV-11  (no deps — build first)
2. DEV-01  (org structure — only needs DEV-11)
3. DEV-02  (accounts — needs DEV-01, DEV-11; enrollment validation built in step 5)
4. DEV-05  (class + sessions — needs DEV-01, DEV-11; calls DEV-08 + DEV-09 which come after)
           NOTE: build Class model and session generation now.
                 Leave enrollment engine incomplete until DEV-08 + DEV-09 exist.
5. DEV-03  (enrollment validation service — needs DEV-05 class model)
           After this: go back and complete DEV-02's enrollment call + DEV-05's enrollment engine.
6. DEV-04  (educator management — needs DEV-05 class model)
7. DEV-08  (attendance — needs DEV-05 sessions + enrollment)
           After this: go back and wire DEV-05 EnrollmentService → DEV-08.
8. DEV-09  (grades — needs DEV-01 scale, DEV-05 enrollment, DEV-07 scores)
           Build rubric + lockRubricIfNeeded now.
           Leave grade computation incomplete until DEV-07 exists.
           After this: wire DEV-05 EnrollmentService → DEV-09 lockRubricIfNeeded.
9. DEV-06  (lessons — needs DEV-05 sessions)
10. DEV-07 (assessments — needs DEV-06 concept build, DEV-08, DEV-09)
           After this: complete DEV-09 grade computation (it reads DEV-07 tables).
11. DEV-10 (meetings — needs DEV-05, DEV-06, DEV-01, DEV-11)
```
