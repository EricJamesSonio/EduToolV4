# DEV-12 — Admin Dashboard & Analytics
**EduTool Developer Guide**
> Covers: Admin dashboard data, enrollment counts, active classes, pending students, grade distribution.

---

## 1. Overview

The Admin dashboard is **read-only aggregate data**. It gives Admin a bird's-eye view of the org's current state. It never exposes live class internals — no unpublished scores, no current grades, no assessment content.

All queries in this guide are scoped to `orgId` from the Admin's JWT. All numbers reflect the **currently active school year** unless stated otherwise.

## 2. Student Enrollment Counts

### 2.1 What it shows

A breakdown of all student accounts in the org, grouped by **Level Section**, then by **account status**.

```
Elementary
  Active:     142
  Pending:     3
  Suspended:   1
  Graduated:   0

High School
  Active:     310
  Pending:     8
  Suspended:   2
  Graduated:   0

Senior High School
  Active:     198
  Pending:     5
  Suspended:   0
  Graduated:  12

College
  Active:     540
  Pending:    11
  Suspended:   4
  Graduated:  87
```

Dropped and Transferred are included in the count but displayed separately so Admin can see the full picture.

### 2.2 Query

```typescript
async getEnrollmentCounts(orgId: string) {
  const counts = await this.prisma.student.groupBy({
    by: ['levelSection', 'status'],
    where: { orgId },
    _count: { id: true },
  });

  // Shape into nested structure:
  // { levelSection: { status: count } }
  const result: Record<string, Record<string, number>> = {};

  for (const row of counts) {
    if (!result[row.levelSection]) result[row.levelSection] = {};
    result[row.levelSection][row.status] = row._count.id;
  }

  return result;
}
```

### 2.3 Display order

Show level sections in this fixed order:
```
1. Elementary
2. High School
3. Senior High School
4. College
```

Show statuses in this fixed order per section:
```
Active → Pending → Suspended → Dropped → Transferred → Graduated
```

Only show a status row if its count > 0. No empty rows.

## 3. Active Class Count

### 3.1 What it shows

Total number of non-archived classes running in the **current semester** of the active school year.

```
Active Classes This Semester:  48
```

### 3.2 Query

```typescript
async getActiveClassCount(orgId: string, schoolYearId: string, semesterId: string) {
  return this.prisma.class.count({
    where: {
      orgId,
      schoolYearId,
      semesterId,
      isArchived: false,
      deletedAt: null,
    },
  });
}
```

Show one number. No breakdown needed here — it is just a count for Admin to know how many active classes exist right now.

## 4. Pending Students

### 4.1 What it shows

Students whose status is `PENDING` — meaning either:
- They have no section assigned (section was full, Admin chose to leave without one), or
- They have unresolved class enrollment conflicts (class was full).

This is an **action item** for Admin. These students cannot log in until resolved.

```
Pending Students:  27

[ View Pending Students ] ← button that takes Admin to the filtered student list
```

### 4.2 Query

```typescript
async getPendingStudentCount(orgId: string) {
  return this.prisma.student.count({
    where: { orgId, status: 'PENDING' },
  });
}
```

Clicking "View Pending Students" just navigates to the student list filtered by `status=PENDING`. No separate page needed — reuse the existing student search from DEV-02/DEV-03.

## 5. Grade Distribution

### 5.1 What it shows

After grades are locked for a class, the distribution of final grade remarks across all students in that class. Admin sees this per class, not a single org-wide blob.

Display it as a **clean sorted table** — one row per class that has locked grades in the current school year.

```
Class                      Sem    Passed   Failed   Incomplete   Total
─────────────────────────────────────────────────────────────────────
BSCS 1A — Data Structures  1st      28        2          1         31
BSCS 1A — Math 101         1st      30        1          0         31
Grade 7 Narra — Science    1st      35        3          2         40
...
```

Sorted by: Level Section → Class Title (alphabetical).

### 5.2 Query

```typescript
async getGradeDistribution(orgId: string, schoolYearId: string) {
  // Get all locked StudentGrade records for this school year
  const grades = await this.prisma.studentGrade.findMany({
    where: {
      isLocked: true,
      class: {
        orgId,
        schoolYearId,
      },
    },
    select: {
      finalGradeRemark: true,  // e.g. "Passed", "Failed", "Incomplete"
      isPassing: true,
      classId: true,
      class: {
        select: {
          title: true,
          levelSection: true,
          semester: { select: { label: true } },
        },
      },
    },
  });

  // Group by classId and count remarks
  const distribution: Record<string, {
    classTitle: string,
    levelSection: string,
    semester: string,
    passed: number,
    failed: number,
    incomplete: number,
    total: number,
  }> = {};

  for (const grade of grades) {
    if (!distribution[grade.classId]) {
      distribution[grade.classId] = {
        classTitle: grade.class.title,
        levelSection: grade.class.levelSection,
        semester: grade.class.semester.label,
        passed: 0, failed: 0, incomplete: 0, total: 0,
      };
    }
    const entry = distribution[grade.classId];
    entry.total += 1;
    if (grade.isPassing) entry.passed += 1;
    else if (grade.finalGradeRemark === 'Incomplete') entry.incomplete += 1;
    else entry.failed += 1;
  }

  // Sort: level section order first, then class title alphabetically
  const levelOrder = ['ELEMENTARY', 'HIGH_SCHOOL', 'SENIOR_HIGH', 'COLLEGE'];
  return Object.values(distribution).sort((a, b) => {
    const levelDiff = levelOrder.indexOf(a.levelSection) - levelOrder.indexOf(b.levelSection);
    if (levelDiff !== 0) return levelDiff;
    return a.classTitle.localeCompare(b.classTitle);
  });
}
```

### 5.3 Display rules

- Only show classes that have at least one locked grade.
- Classes with zero locked grades do not appear in this table.
- If no grades are locked yet for the school year, show: "No locked grades yet for this school year."
- The table is read-only. Admin cannot click into individual student grades from here.

## 6. Dashboard API Endpoint

One endpoint that returns all four data points in a single call. The dashboard loads fast — no separate requests.

```typescript
// GET /api/v1/admin/dashboard
// Auth: Admin only (JwtAuthGuard + Roles(Role.ADMIN))

async getDashboard(orgId: string, schoolYearId: string, semesterId: string) {
  const [enrollmentCounts, activeClassCount, pendingCount, gradeDistribution] =
    await Promise.all([
      this.getEnrollmentCounts(orgId),
      this.getActiveClassCount(orgId, schoolYearId, semesterId),
      this.getPendingStudentCount(orgId),
      this.getGradeDistribution(orgId, schoolYearId),
    ]);

  return {
    enrollmentCounts,
    activeClassCount,
    pendingStudentCount: pendingCount,
    gradeDistribution,
  };
}
```

All four queries run in parallel via `Promise.all`. The dashboard does not block on any single slow query.

## 7. Build Order

```
1. getEnrollmentCounts query + endpoint
2. getActiveClassCount query
3. getPendingStudentCount query
4. getGradeDistribution query
5. Combined /admin/dashboard endpoint (Promise.all)
6. Admin UI: dashboard page with 4 sections
   - Enrollment counts table (level section × status)
   - Active class count (single number)
   - Pending students count + "View Pending" button
   - Grade distribution table (sorted, locked classes only)
```
