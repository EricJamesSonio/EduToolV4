## What is EduTool?

EduTool is an all-in-one platform designed to make school management easier, faster, and more organized.

Whether you are an administrator, educator, or student, EduTool brings everything together in one place — from classes and grading to communication and meetings.

---

## Features

<img src="./.Images/home/features.png" alt="EduTool Features" />

### For Schools and Administrators

- Manage students, educators, and classes
- Monitor academic performance in real time
- Organize subjects, sections, and programs
- Generate reports quickly
- Maintain structured and secure records

### For Educators

- Create and manage classes
- Track attendance
- Assign activities and assessments
- Grade students efficiently
- Host online class meetings

### For Students

- Access classes and lessons anytime
- Submit assignments online
- Join live class sessions
- Track grades and progress
- Receive announcements
